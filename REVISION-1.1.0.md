# Codex skill revision 1.1.0

The operational gates are an adaptation for agent use, not a verbatim structure
attributed to the source authors. The revision keeps the method and source references,
allows a concise requested output and updates only analysis dependent on a changed
interest. Sources retain their recorded verification date; this revision does not
claim that the historical PDF links were revalidated. The Claude variant is separate.

The installable Codex package is codex/metodo-strutturale-dinamico. Root files
remain compatible mirrors. Installing the whole repository would also expose
the nested Claude variant, so the explicit package path avoids duplicate discovery.
